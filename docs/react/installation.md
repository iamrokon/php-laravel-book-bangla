# রিঅ্যাক্ট ইনস্টলেশন ও সেটআপ (React Installation & Setup)

রিঅ্যাক্ট প্রজেক্ট তৈরি করার জন্য আধুনিক ওয়েব ডেভেলপমেন্টে বেশ কয়েকটি চমৎকার টুলস ও বিল্ডার রয়েছে। এই চ্যাপ্টারে আমরা শিখবো কীভাবে নতুন `react.dev` ওয়েবসাইট অনুযায়ী একটি মডার্ন রিঅ্যাক্ট প্রজেক্ট ইনস্টল ও লোকাল মেশিনে সেটআপ করতে হয়।

---

## ১. ফ্রেমওয়ার্ক দিয়ে রিঅ্যাক্ট প্রজেক্ট তৈরি

রিঅ্যাক্টের নতুন অফিশিয়াল ডকুমেন্টেশনে ক্লায়েন্ট সাইড রেন্ডারিং এবং সার্ভার সাইড রেন্ডারিং (SSR)-এর সুবিধা পেতে সরাসরি **Next.js** বা **Remix**-এর মতো ফ্রেমওয়ার্ক ব্যবহারের রিকমেন্ডেশন দেওয়া হয়েছে। এর জন্য কমান্ডটি হলো:

```bash
npx create-next-app@latest
```

কিন্তু আমরা যদি কোনো ভারী ফ্রেমওয়ার্ক ছাড়া সরাসরি শুধুমাত্র একটি পিওর ক্লায়েন্ট-সাইড সিঙ্গেল পেজ রিঅ্যাক্ট অ্যাপ্লিকেশন বানাতে চাই, তবে কী করবো?

---

## ২. Vite দিয়ে আধুনিক রিঅ্যাক্ট প্রজেক্ট ইনস্টলেশন

অতীতে ক্লায়েন্ট-সাইড রিঅ্যাক্ট প্রজেক্ট বানাতে **Create React App (CRA)** ব্যবহার করা হতো। কিন্তু সময়ের সাথে সাথে এটি অনেক ধীরগতির (slow) এবং ভারী হয়ে গেছে। এই সমস্যার সমাধান করেছে **Vite** (উচ্চারণ: ভিট)। 

### Vite কেন ব্যবহার করবেন?
- **Hot Module Replacement (HMR):** কোডে যেকোনো পরিবর্তন আনার সাথে সাথে ব্রাউজারে পেজ রিলোড ছাড়াই তা চোখের পলকে আপডেট হয়ে যায়।
- **SWC Compiler:** Babel-এর চেয়েও দ্রুত কোড ট্রান্সপাইল করার জন্য এতে Rust দিয়ে তৈরি SWC কম্পাইলার ব্যবহার করা যায়।
- **Fast Build:** এটি আধুনিক ES Modules ব্যবহার করে ডেভেলপমেন্ট স্পিড বহু গুণ বাড়িয়ে দেয়।

### প্রজেক্ট ইনস্টলেশন ধাপসমূহ:

টার্মিনালে নিচের কমান্ডটি রান করুন:
```bash
npm create vite@latest
```

কমান্ডটি চালানোর পর নিচের অপশনগুলো সিলেক্ট করুন:
1. **Project name:** `myapp` (আপনার প্রজেক্টের নাম দিন)
2. **Select a framework:** `React`
3. **Select a variant:** `JavaScript` অথবা `JavaScript + SWC` (SWC সিলেক্ট করা রিকমেন্ডেড, কারণ এটি প্রজেক্ট বিল্ড ও রান আরও দ্রুত করে)।

প্রজেক্ট ফোল্ডারটি তৈরি হওয়ার পর নিচের কমান্ডগুলো রান করে ডিপেন্ডেন্সি ইনস্টল ও প্রজেক্ট রান করুন:

```bash
cd myapp
npm install
npm run dev
```

লোকাল সার্ভার চালু হওয়ার পর স্ক্রিনে একটি URL আসবে (সাধারণত `http://localhost:5173/`), এটি ব্রাউজারে ওপেন করলে আপনার তৈরি করা রিঅ্যাক্ট অ্যাপটি দেখতে পাবেন।

### কাজের প্রয়োজনীয় কমান্ডসমূহ:
- `npm run dev` - লোকাল ডেভেলপমেন্ট সার্ভার রান করতে।
- `npm run build` - প্রোডাকশন রেডি বিল্ড (Production Bundle) তৈরি করতে।

## ৩. প্রজেক্টের ডিরেক্টরি স্ট্রাকচার

Vite দিয়ে তৈরি রিঅ্যাক্ট প্রজেক্টের গুরুত্বপূর্ণ ফোল্ডার ও ফাইলসমূহ:

- **src/main.jsx:** এটি আমাদের রিঅ্যাক্ট অ্যাপ্লিকেশনের মেইন এন্ট্রি পয়েন্ট (Entry Point), যা আমাদের কোডকে ব্রাউজার ডমে রেন্ডার করে।
- **src/App.jsx:** এটি আমাদের অ্যাপের মূল রুট কম্পোনেন্ট (Root Component)। সমস্ত ছোট ছোট কম্পোনেন্টগুলো এই ফাইলের ভেতরেই এসে অ্যাসেম্বল করা হয়।
- **src/index.css:** এখানে আমাদের গ্লোবাল সিএসএস স্টাইলগুলো রাখা হয়।
- **src/App.css:** নির্দিষ্টভাবে `App` কম্পোনেন্টের স্টাইলিং করার জন্য এটি ব্যবহৃত হয়।

## ৪. রিঅ্যাক্ট শেখার পূর্বশর্ত (React Prerequisites)

রিঅ্যাক্ট পুরোপুরি জাভাস্ক্রিপ্ট দিয়ে তৈরি। তাই রিঅ্যাক্ট শেখা শুরু করার আগে জাভাস্ক্রিপ্টের মডার্ন ফিচারগুলো (ES6+) ভালোভাবে আয়ত্ত করে নিতে হবে। এর মধ্যে গুরুত্বপূর্ণ বিষয়গুলো হলো:

- `let` এবং `const` (Block-scoped Variables)
- Arrow Functions (অ্যারো ফাংশন)
- Template Literals (টেম্পলেট স্ট্রিং `${}`)
- Array Methods (`map()`, `filter()`, `reduce()`)
- Object & Array Destructuring (ডিস্ট্রাকচারিং)
- Spread & Rest Operators (`...`)
- ES Modules (`import` ও `export` সিনট্যাক্স)

## ৫. রিঅ্যাক্ট বয়লারপ্লেট কোড (React Boilerplate Code)

ক্রিয়েট-রিঅ্যাক্ট-অ্যাপ (CRA) দিয়ে তৈরি রিঅ্যাক্ট প্রজেক্টে আমাদের প্রধান ফাইলগুলোর বেসিক স্ট্রাকচার যেমন থাকে:

### App.js
```javascript
function App() {
  return (
    <div className="App">
      <h1>Hello World</h1>
    </div>
  );
}

export default App;
```

### index.js
```javascript
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';

// HTML এর root ডিভকে সিলেক্ট করে রিঅ্যাক্ট রুট তৈরি
const root = ReactDOM.createRoot(document.getElementById('root'));

// রিঅ্যাক্ট অ্যাপটিকে রেন্ডার করা
root.render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```

টার্মিনালে `yarn start` বা `npm start` টাইপ করে এন্টার চাপলে লোকালহোস্টে `localhost:3000` পোর্টে আপনার বয়লারপ্লেট প্রজেক্টটি রান হয়ে যাবে।
