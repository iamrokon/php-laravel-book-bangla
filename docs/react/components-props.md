# কম্পোনেন্ট ও প্রপস (React Components and Props Core Concept)

রিঅ্যাক্ট অ্যাপ্লিকেশনের অত্যন্ত গুরুত্বপূর্ণ একটি স্তম্ভ হলো **Component (কম্পোনেন্ট)** এবং **Props (প্রপস)**। এই চ্যাপ্টারে আমরা জানবো কীভাবে কম্পোনেন্ট তৈরি করতে হয় এবং কীভাবে প্রপসের সাহায্যে এক কম্পোনেন্ট থেকে অন্য কম্পোনেন্টে ডেটা পাস করতে হয়।

---

## ১. রিঅ্যাক্ট কম্পোনেন্ট (React Component)

রিঅ্যাক্ট এলিমেন্টগুলো কোনো নিজস্ব স্টেট বা ফাংশনালিটি বহন করে না; সেগুলো কেবল স্ক্রিনে দেখানোর নির্দিষ্ট স্থির অবজেক্ট। কিন্তু বাস্তব জীবনে আমাদের এমন রিইউজেবল ডাইনামিক ব্লক প্রয়োজন যা তাদের নিজস্ব স্টেট ধরে রাখতে পারবে এবং লজিক হ্যান্ডেল করতে পারবে। একেই রিঅ্যাক্টে **Component** বলা হয়।

কম্পোনেন্টকে মূলত একটি জাভাস্ক্রিপ্ট ফাংশনের মতো চিন্তা করা যায়, যা কিছু ইনপুট রিসিভ করে এবং আউটপুট হিসেবে রিঅ্যাক্ট এলিমেন্ট রিটার্ন করে।

### ফাংশনাল কম্পোনেন্ট (Functional Component)

সবচেয়ে সহজ উপায়ে ফাংশন লিখে আমরা কম্পোনেন্ট তৈরি করতে পারি।

```javascript
function Clock() {
  return (
    <h1 className="heading">
      <span className="text">Hello {new Date().toLocaleTimeString()}</span>
    </h1>
  );
}

// রেন্ডার করার সময় কম্পোনেন্টকে এইচটিএমএল ট্যাগের মতো ব্যবহার করতে হয়
ReactDOM.render(<Clock />, document.getElementById('root'));
```

আমরা যখন ইউজার-ডিফাইন্ড ফাংশনকে HTML ট্যাগের মতো (যেমন—`<Clock />`) ব্যবহার করি, রিঅ্যাক্ট সেটিকে একটি কম্পোনেন্ট হিসেবে রান করায়। 

> [!IMPORTANT]
> **কম্পোনেন্টের নাম অবশ্যই Capital Letter (বড় হাতের অক্ষর) দিয়ে শুরু হতে হবে।** 
> যেমন: `Clock`। আমরা যদি এটি ছোট হাতের অক্ষরে `clock` লিখতাম, তবে রিঅ্যাক্ট এটিকে একটি সাধারণ HTML বিল্ট-ইন ট্যাগ মনে করে ভুল করতো এবং রান করতো না।

---

## ২. প্রপস (Props)

সাধারণ HTML ট্যাগের মতোই আমরা রিঅ্যাক্ট কম্পোনেন্টে কাস্টম অ্যাট্রিবিউট বা ডেটা পাস করতে পারি। এই ইনপুট অ্যাট্রিবিউটগুলোকে রিঅ্যাক্টে বলা হয় **Props (Properties)**।

কম্পোনেন্টটি তখন তার প্যারামিটার হিসেবে এই প্রপসগুলোকে একটি অবজেক্টের আকারে রিসিভ করে। আমরা কার্লি ব্রেস ব্যবহার করে সরাসরি প্রোপার্টিগুলো ডিস্ট্রাকচার করে নিতে পারি:

```javascript
// locale প্রপসটি প্যারামিটার হিসেবে রিসিভ করা হচ্ছে
function Clock({ locale }) {
  return (
    <span>Hello {new Date().toLocaleTimeString(locale)}</span>
  );
}

// locale প্রপস হিসেবে "bn-BD" পাস করা হলো
ReactDOM.render(<Clock locale="bn-BD" />, document.getElementById('root'));
```

এখানে আমরা `locale="bn-BD"` পাস করেছি, যার ফলে ঘড়িটি বাংলা লোকাল অনুযায়ী বাংলায় সময় প্রদর্শন করবে। এভাবেই আমাদের ডিজাইন করা কম্পোনেন্টটি প্রপসের সাহায্যে সম্পূর্ণ ডাইনামিক হয়ে ওঠে।

## ৩. ক্লাস কম্পোনেন্ট (Class Component)

ফাংশনাল কম্পোনেন্ট ছাড়াও রিঅ্যাক্টে কম্পোনেন্ট তৈরি করার আরেকটি ঐতিহ্যবাহী সিনট্যাক্স রয়েছে, যাকে বলা হয় **Class Component (ক্লাস কম্পোনেন্ট)**।

ক্লাস কম্পোনেন্ট হলো মূলত স্টেটফুল (Stateful) কম্পোনেন্ট। রিঅ্যাক্ট ১৬.৮ সংস্করণে হুকস (Hooks) আসার আগে, শুধুমাত্র ক্লাস কম্পোনেন্টেই স্টেট (State) এবং বিভিন্ন লাইফসাইকেল মেথড (যেমন: `componentDidMount`, `componentWillUnmount` ইত্যাদি) ব্যবহার করা যেত।

নিচে একটি ক্লাস কম্পোনেন্টের উদাহরণ দেওয়া হলো:

```javascript
import React from 'react';

class Clock extends React.Component {
  // ক্লাস কম্পোনেন্টে স্টেট ডিফাইন করার জন্য constructor ব্যবহার করা হয়
  constructor(props) {
    super(props);
    this.state = { date: new Date() };
  }

  // কম্পোনেন্টটি স্ক্রিনে রেন্ডার হওয়ার পর এই লাইফসাইকেল মেথডটি রান হয়
  componentDidMount() {
    this.timerID = setInterval(
      () => this.tick(),
      1000
    );
  }

  // কম্পোনেন্টটি ডম থেকে রিমুভ করার আগে টাইমারটি মেমরি থেকে ক্লিয়ার করা হয়
  componentWillUnmount() {
    clearInterval(this.timerID);
  }

  tick() {
    // ক্লাস কম্পোনেন্টে স্টেট আপডেট করতে setState ব্যবহার করতে হয়
    this.setState({
      date: new Date()
    });
  }

  // ক্লাস কম্পোনেন্টে স্ক্রিনে কিছু দেখানোর জন্য render() মেথডটি থাকা আবশ্যক
  render() {
    return (
      <h1 className="heading">
        <span className="text">
          Hello {this.state.date.toLocaleTimeString(this.props.locale)}
        </span>
      </h1>
    );
  }
}

ReactDOM.render(<Clock locale="bn-BD" />, document.getElementById('root'));
```

### ক্লাস কম্পোনেন্ট বনাম ফাংশনাল কম্পোনেন্ট

- **ফাংশনাল কম্পোনেন্ট:** এটি মূলত একটি সাধারণ জাভাস্ক্রিপ্ট ফাংশন যা প্রপস রিসিভ করে রিঅ্যাক্ট এলিমেন্ট রিটার্ন করে। বর্তমানে **React Hooks** (যেমন—`useState`, `useEffect`) আসার কারণে ক্লাস কম্পোনেন্ট ছাড়াই ফাংশনাল কম্পোনেন্টে স্টেট ও লাইফসাইকেলের সব কাজ করা যায়। তাই আধুনিক প্রজেক্টে এটিই সবচেয়ে বেশি জনপ্রিয় এবং অফিসিয়ালি রিকমেন্ডেড পদ্ধতি।
- **ক্লাস কম্পোনেন্ট:** এটি ES6 ক্লাস যা `React.Component`-কে এক্সটেন্ড করে এবং এতে একটি `render()` মেথড থাকে। এটি ওল্ড স্কুল বা লিগ্যাসি কোডবেজে বেশি দেখা যায়। নতুন প্রজেক্টে ক্লাস কম্পোনেন্ট সাধারণত ব্যবহার করা হয় না।
