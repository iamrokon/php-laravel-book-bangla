# মডিউল ৮: রাউটিং পরিচিতি (Introduction to Routing)

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** লারাভেলে রাউটিং (Routing) কি এবং বিভিন্ন প্রকার রাউট ও রাউট প্যারামিটার উদাহরণসহ লিখ

ওয়েব অ্যাপ্লিকেশনে ক্লায়েন্টের ব্রাউজার থেকে কোনো রিকোয়েস্ট বা ইউআরএল হিট করলে তা ব্যাকএন্ডে কীভাবে রেসপন্স করবে, তা নির্ধারণ করাই হলো **Routing** এর কাজ। লারাভেলের রাউটিং সিস্টেম অত্যন্ত সহজ কিন্তু অসম্ভব শক্তিশালী।

---

## ১. লারাভেলে রাউট কোথায় থাকে?

লারাভেলের সমস্ত সাধারণ ওয়েব পেজের রাউটগুলো ডিফাইন করা থাকে **`routes/web.php`** ফাইলে। 

### ক. বেসিক রাউট (HTTP GET Request)
যেকোনো সাধারণ পেজ ব্রাউজ করার জন্য আমরা HTTP GET রিকোয়েস্ট ব্যবহার করি। নিচে একটি বেসিক গেট রাউটের উদাহরণ দেওয়া হলো:
```php
use Illuminate\Support\Facades\Route;

Route::get('/', function () {
    return "Hello Laravel! Welcome to LWR Book.";
});
```
এই রাউটটি রুট ইউআরএল (`/`) হিট করা হলে রেসপন্স হিসেবে `Hello Laravel!...` টেক্সটটি ব্রাউজারে রিটার্ন করবে।

### খ. পোস্ট রাউট (HTTP POST Request)
কোনো ফর্ম সাবমিট করা বা সার্ভারে নতুন ডেটা পাঠানোর জন্য HTTP POST রিকোয়েস্ট ব্যবহার করা হয়:
```php
Route::post('/contact', function () {
    return "Contact form submitted successfully!";
});
```

## ২. রিকোয়েস্ট অবজেক্ট ও ডেটা রিড করা (Request Object)

ইউজার যখন গেট বা পোস্ট রিকোয়েস্টের মাধ্যমে সার্ভারে কোনো অতিরিক্ত ডেটা পাঠায় (যেমন ফর্মের ইনপুট বা কুয়েরি প্যারামিটার), তখন আমরা লারাভেলের **`Illuminate\Http\Request`** ক্লাসের সাহায্য নিয়ে সেই ডেটা রিড করতে পারি।

### উদাহরণ (Query Parameters):
ধরি আমাদের একটি রাউট রয়েছে `/about` এবং সেখানে ইউজার ব্রাউজারে `http://localhost:8000/about?ref=github` লিখে হিট করলেন। এই কোয়েরি প্যারামিটার `ref` রিড করার কোড:
```php
use Illuminate\Http\Request;

Route::get('/about', function (Request $request) {
    // সমস্ত কুয়েরি প্যারামিটার রিড করতে
    $queryParams = $request->query(); 
    
    // অথবা নির্দিষ্ট একটি কুয়েরি প্যারামিটার পেতে
    $ref = $request->query('ref'); 

    // ডিবাগিংয়ের জন্য রিকোয়েস্ট অবজেক্ট ডাম্প করে দেখা
    // var_dump($request);
    
    return "Referrer is: " . $ref;
});
```

## ৩. আর্টিসান রাউট লিস্ট কমান্ডস (Artisan Route List Commands) ★

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** লারাভেলে আপনার প্রজেক্টের সমস্ত রেজিস্টার্ড রাউটগুলোর তালিকা কীভাবে টার্মিনালে দেখতে পারেন?

লারাভেল আর্টিসান টুলের মাধ্যমে খুব সহজেই প্রজেক্টের সমস্ত রাউট এবং তাদের সংশ্লিষ্ট মিডলওয়্যার, কন্ট্রোলার ও ইউআরএল প্যাটার্ন দেখে নেওয়া যায়।

### ক. সমস্ত রাউটের তালিকা দেখা:
টার্মিনালে নিচের কমান্ডটি রান করুন:
```bash
php artisan route:list
```

### খ. হেল্প অপশন দেখা:
রাউট লিস্ট কমান্ডের জন্য আর কী কী অতিরিক্ত ফ্ল্যাগ বা ফিচার রয়েছে তা দেখতে হেল্প কমান্ডটি রান করুন:
```bash
php artisan route:list -h
```

### গ. নির্দিষ্ট কোনো পাথের (Path) রাউট ফিল্টার করা:
আপনার প্রজেক্টে যদি অনেক রাউট থাকে এবং আপনি শুধুমাত্র একটি নির্দিষ্ট পাথের রাউট দেখতে চান (যেমন `about` সংবলিত রাউটগুলো):
```bash
php artisan route:list --path=about
```

## ৪. ডাইনামিক রাউটিং ও রাউট প্যারামিটারস (Dynamic Routing)

অনেক সময় আমাদের রাউটগুলো ফিক্সড বা স্ট্যাটিক না হয়ে ডাইনামিক হওয়ার প্রয়োজন পড়ে। যেমন: নির্দিষ্ট কোনো ইউজারের প্রোফাইল দেখতে আমরা `/users/1` বা `/users/42` ইউআরএল ব্যবহার করি।

### ক. ডাইনামিক রাউট প্যারামিটার (Required Parameter):
ইউআরএল-এর যে অংশটি পরিবর্তনশীল, সেটিকে কার্লি ব্র্যাকেট `{}` এর মধ্যে লিখতে হয় এবং রাউট হ্যান্ডলার ফাংশনে আর্গুমেন্ট হিসেবে পাস করতে হয়:
```php
Route::get('/users/{id}', function (string $id) {
    // dd() এর পূর্ণরূপ হলো Dump and Die। এটি ভেরিয়েবল ডাম্প করে কোড এক্সিকিউশন বন্ধ করে দেয়।
    dd($id); 
});
```
*দ্রষ্টব্য: এই রাউটটি কাজ করতে অবশ্যই ইউআরএল-এ আইডি (যেমন `/users/5`) প্রদান করতে হবে, না হলে এটি ৪0৪ (Not Found) এরর দেখাবে।*

### খ. অপশনাল রাউট প্যারামিটার (Optional Parameter)
যদি প্যারামিটারটি দেওয়া বাধ্যতামূলক না হয়, তবে প্যারামিটারের নামের শেষে একটি প্রশ্নবোধক চিহ্ন `?` দিতে হবে। এ ক্ষেত্রে ফাংশনের আর্গুমেন্টে একটি ডিফল্ট ভ্যালু (যেমন `null` বা কোনো ফিক্সড ভ্যালু) সেট করে দিতে হয়:
```php
Route::get('/users/{id?}', function (string $id = null) {
    if ($id === null) {
        return "Show list of all users";
    }
    return "Showing details for user ID: " . $id;
});
```
এই ক্ষেত্রে ইউজার `/users` টাইপ করলেও রাউটটি সফলভাবে কাজ করবে এবং ডিফল্ট মেসেজটি শো করবে।
