# Laravel Directory Structure

লারাভেল প্রজেক্টের ফোল্ডার স্ট্রাকচার বেশ বড় মনে হতে পারে, তবে এটি অত্যন্ত সুশৃঙ্খল। নিচে গুরুত্বপূর্ণ ফোল্ডারগুলোর কাজ দেওয়া হলো:

- **app/**: এখানে আপনার প্রজেক্টের মূল লজিক থাকে (Models, Controllers, Providers)।
- **bootstrap/**: ফ্রেমওয়ার্ক বুটস্ট্র্যাপ করার ফাইলগুলো এখানে থাকে।
- **config/**: প্রজেক্টের সব কনফিগারেশন ফাইল এখানে থাকে।
- **database/**: ডাটাবেজ মাইগ্রেশন, সিডার এবং ফ্যাক্টরি এখানে থাকে।
- **public/**: এটি প্রজেক্টের এন্ট্রি পয়েন্ট (index.php) এবং এখানে CSS, JS, Images রাখা হয়।
- **resources/**: এখানে আপনার View (Blade files), ল্যাঙ্গুয়েজ এবং আন-কম্পাইলড রিসোর্স থাকে।
- **routes/**: সব ধরণের রাউটিং এখানে ডিফাইন করা হয় (web.php, api.php)।
- **storage/**: লগ ফাইল এবং ইউজারের আপলোড করা ফাইল এখানে জমা হয়।
- **vendor/**: আপনার ইউজ করা সব প্যাকেজ বা লাইব্রেরি এখানে থাকে (Composer-এর মাধ্যমে)।
- **.env**: এখানে ডাটাবেজ এবং অন্যান্য এনভায়রনমেন্ট কনফিগারেশন রাখা হয়।
