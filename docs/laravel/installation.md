# Laravel Installation

লারাভেল ইনস্টল করার প্রধান মাধ্যম হলো **Composer**। 

### ১. সার্ভার রিকোয়ারমেন্ট
লারাভেল ইনস্টল করার আগে নিশ্চিত হোন আপনার পিসিতে **PHP** এবং **Composer** ইনস্টল করা আছে।

### ২. লারাভেল ইনস্টলার এর মাধ্যমে
প্রথমে লারাভেল ইনস্টলার ডাউনলোড করে নিন:
```bash
composer global require laravel/installer
```
এরপর নতুন প্রজেক্ট তৈরি করতে লিখুন:
```bash
laravel new my-app
```

### ৩. সরাসরি কম্পোজারের মাধ্যমে
```bash
composer create-project laravel/laravel my-app
```

ইনস্টলেশন শেষ হলে আপনার প্রজেক্টটি রান করতে লিখুন:
```bash
php artisan serve
```
এরপর ব্রাউজারে `http://127.0.0.1:8000` লিঙ্কে প্রবেশ করলে লারাভেলের ওয়েলকাম পেজটি দেখতে পাবেন।
