# মডিউল ৯(২): সেশন ম্যানেজমেন্ট (Sessions in Laravel)

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** লারাভেলে সেশন ম্যানেজমেন্ট (Session Management) কি এবং সেশন কীভাবে ব্যবহার ও হ্যান্ডেল করা হয় উদাহরণসহ লিখ

ওয়েব অ্যাপ্লিকেশন মূলত **Stateless**। এর মানে হলো প্রতিবার ব্রাউজার থেকে যখন কোনো রিকোয়েস্ট আসে, সার্ভার তার পূর্বের রিকোয়েস্টের কোনো তথ্য মনে রাখতে পারে না। এই সমস্যার সমাধান করতেই ব্যবহার করা হয় **Session**। সেশনের মাধ্যমে আমরা ইউজারের তথ্য বিভিন্ন রিকোয়েস্টের মাঝে সাময়িকভাবে সংরক্ষণ করে রাখতে পারি।

লারাভেলে সেশন হ্যান্ডেল করার জন্য অত্যন্ত চমৎকার মেকানিজম রয়েছে। আমরা চাইলে `Request` ক্লাসের অবজেক্ট দিয়ে, `Session` ফাসাদের সাহায্যে অথবা গ্লোবাল `session()` হেল্পার ফাংশনের মাধ্যমে সেশন পরিচালনা করতে পারি।

---

## ১. সেশন ভ্যালু সেট ও গেট করা (Putting & Getting Session Data)

লারাভেলে সেশনে ডেটা রাখতে এবং পড়তে নিচে ৩টি পদ্ধতি দেখানো হলো:

```php
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Session;

Route::get('/', function (Request $request) {
    // পদ্ধতি ১: Request ক্লাসের অবজেক্ট দিয়ে সেশন সেট করা
    $request->session()->put('key', 'value');

    // পদ্ধতি ২: Session ফাসাদ ব্যবহার করে সেট করা
    Session::put('name', 'Al Nahian');

    // পদ্ধতি ৩: গ্লোবাল session() হেল্পার দিয়ে সেট করা (সবচেয়ে সহজ)
    session(['theme' => 'dark']); // কি-ভ্যালু অ্যারে আকারে
});
```

### সেশন থেকে ডেটা রিড করা:
```php
// সেশন থেকে নির্দিষ্ট ডেটা গেট করা
$name = session('name'); 

// Request অবজেক্ট দিয়ে রিড করা
$key = $request->session()->get('key');

// সেশনের সমস্ত ডেটা অ্যারে আকারে পাওয়া
$allSessions = session()->all();
```

## ২. সেশনে অ্যারে নিয়ে কাজ করা (Working with Arrays in Session)

সেশনে আমরা জটিল অ্যারে ডেটাও সংরক্ষণ করতে পারি এবং লারাভেলের ডট নোটেশনের সাহায্যে সহজে এক্সেস করতে পারি।

### ক. সেশনে অ্যারে রাখা:
```php
session(['team' => [
    'Mashrafee',
    'Sakib',
    'Tamim'
]]);
```

### খ. অ্যারেতে নতুন আইটেম যুক্ত করা (`push()`):
সেশনে সংরক্ষিত কোনো অ্যারের ভেতর নতুন কোনো আইটেম পুশ করতে `push()` মেথড ব্যবহার করা হয়:
```php
session()->push('team', 'Mushfiq');
```

### গ. ডট নোটেশন (Dot Notation) ব্যবহার করে নির্দিষ্ট ইনডেক্স অ্যাক্সেস:
```php
$player = session('team.1'); 
// আউটপুট: Sakib (যেহেতু ইনডেক্স ০-তে Mashrafee এবং ১-এ Sakib)
```

### ঘ. ডিফল্ট ভ্যালু সাপোর্ট (Default Value Fallback):
যদি সেশনে নির্দিষ্ট কি (key) না থাকে, তবে কোনো এরর না দেখিয়ে একটি ডিফল্ট ভ্যালু রিটার্ন করানো যায়:
```php
$theme = session('theme', 'dark');
// সেশনে 'theme' এর ভ্যালু না থাকলে 'dark' রিটার্ন করবে
```

## ৩. সেশন থেকে ডেটা ডিলিট করা (Removing Session Data)

- **নির্দিষ্ট কোনো কি সেশন থেকে রিমুভ করা (`forget`):**
  ```php
  session()->forget('name');
  ```
- **একসাথে একাধিক কি সেশন থেকে রিমুভ করা:**
  ```php
  session()->forget(['name', 'theme']);
  ```
- **সেশনের সমস্ত ডেটা সম্পূর্ণ মুছে ফেলা (`flush`):**
  ```php
  session()->flush();
  ```

## ৪. সেশন চেক করার মেথডসমূহ (Checking Session Existence)

সেশনে কোনো ডাটা আছে কিনা তা যাচাই করার জন্য লারাভেলে কয়েকটি চমৎকার মেকানিজম রয়েছে:

- **`has()`:** সেশনে নির্দিষ্ট কি-টি রয়েছে কিনা এবং তার ভ্যালু `null` নয় তা চেক করতে ব্যবহার করা হয় (ভ্যালু থাকলে `true` রিটার্ন করবে):
  ```php
  if (session()->has('name')) {
      // সেশনে 'name' কী-টি রয়েছে এবং ভ্যালু খালি নয়
  }
  ```
- **`exists()`:** সেশনে কি-টি আসলেই সেট করা হয়েছে কিনা তা চেক করে (ভ্যালু `null` হলেও এটি `true` রিটার্ন করবে):
  ```php
  if (session()->exists('name')) {
      // সেশনে 'name' কী-টি বিদ্যমান
  }
  ```
- **`missing()`:** সেশনে নির্দিষ্ট আইটেমটি মিসিং বা অনুপস্থিত কিনা তা দেখতে:
  ```php
  if (session()->missing('avocado')) {
      // 'avocado' নামে সেশনে কোনো আইটেম নেই (true রিটার্ন করবে)
  }
  ```

## ৫. সেশন পুল মেথড (Pull Method)

সেশন থেকে কোনো ডেটা রিড করার পাশাপাশি একই সাথে সেই ডেটাটি সেশন থেকে মুছে ফেলতে চাইলে **`pull()`** মেথড ব্যবহার করা হয়:
```php
$name = session()->pull('name');
// এটি 'name' সেশন ভ্যালু রিটার্ন করবে এবং সেশন থেকে 'name' মুছে ফেলবে
```

## ৬. সেশন ইনক্রিমেন্ট ও ডিক্রিমেন্ট (Increment & Decrement)

সেশনে যদি কোনো সংখ্যার হিসাব (যেমন ভিজিটর সংখ্যা বা কার্ট আইটেম কাউন্ট) রাখতে হয়, তবে আমরা সরাসরি সেশনেই ইনক্রিমেন্ট বা ডিক্রিমেন্ট করতে পারি।

```php
Route::get('/visit', function() {
    // প্রতি ভিজিটে সেশন ভ্যালু ১ করে বাড়বে
    $visitors = session()->increment('visitors');
    echo "Total visitors: " . $visitors;
});
```

### কাস্টম সংখ্যা দিয়ে বাড়ানো বা কমানো:
```php
// সেশন ভ্যালু প্রতিবার ৫ করে বৃদ্ধি পাবে (৫, ১০, ১৫...)
session()->increment('visitors', 5);

// একইভাবে ভ্যালু কমানোর জন্য:
session()->decrement('visitors', 2);
```

## ৭. ফ্ল্যাশ মেসেজ (Flash Messages) ★

অনেক সময় আমাদের এমন কিছু সেশন ডেটা দরকার হয় যা শুধুমাত্র পরবর্তী রিকোয়েস্টের সময় পর্যন্ত মেমরিতে থাকবে এবং তারপরেই স্বয়ংক্রিয়ভাবে ডিলিট হয়ে যাবে (যেমন: ফর্ম সাবমিট করার পর "সফলভাবে সেভ হয়েছে" মেসেজ প্রদর্শন)। লারাভেলে এই ধরনের ডেটাকে **Flash Session** বলা হয়।

### ক. সেশনে ফ্ল্যাশ মেসেজ সেট করা:
```php
Route::post('/save', function() {
    // শুধুমাত্র পরবর্তী ১টি রিকোয়েস্টের জন্য এই ডাটা মেমরিতে থাকবে
    session()->flash('status', 'Your email address has been saved successfully.');
    
    return redirect('/dashboard');
});
```

### খ. ব্লেড ভিউ ফাইলে ফ্ল্যাশ মেসেজ শো করা:
```html
@if (session('status'))
    <div class="alert alert-success">
        {{ session('status') }}
    </div>
@endif
```

> [!TIP]
> লারাভেলে আরো আকর্ষণীয় উপায়ে টোস্ট বা নোটিফিকেশন মেসেজ ফ্ল্যাশ করতে ডেভেলপাররা প্রায়শই **PHPFlasher** লাইব্রেরি ব্যবহার করে থাকেন। এটি সহজে চমৎকার ইন্টারফেস প্রদর্শন করতে সাহায্য করে।
