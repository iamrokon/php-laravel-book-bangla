Module 12: Episode 4: Eloquent VS Query Builder

Eloquent হলো ORM যা একটা মডেলের মাধ্যমে ডাটাবেজের একটা টেবিলকে সূচিত করে এবং সে উক্ত টেবিলের ডাটাকে মেমোরিতে রেখে সেটাকে ম্যানিপুলেট করতে পারে।

কোয়েরি বিল্ডারের কোনো মডেল নাই, সে সরাসরি ডাটাবেজের সাথে কমিউনিকেট করে। তবে কোয়েরি বিল্ডারেও অবজেক্ট ওরিয়েন্টেড ওয়েতে কাজ করা যায়। কোয়েরি বিল্ডারে DB ফ্যাসেডের মাধ্যমে কোয়েরি করা যায়।

$users = DB::table('users')->get();
-> users টেবিলের সব ডাটা তুলে আনবে।

অনেক সময় জটিল কোয়েরি Eloquent দিয়ে লেখা সম্ভব হয় না। তখন Query Builder ব্যবহৃত হয়।

Query Builder পারফরম্যান্সের দিক থেকে Faster।
তবে খুব দরকার না পড়লে Query Builder ব্যবহৃত হয় না। Eloquent দিয়ে কোয়েরি করলে তা Model রিটার্ন করে। কিন্তু কোয়েরি বিল্ডার মডেল রিটার্ন করে না।
