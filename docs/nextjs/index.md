# Next.js পরিচিতি

**Next.js** হলো React-এর একটি শক্তিশালী framework যা ওয়েব অ্যাপ্লিকেশন তৈরিকে আরও সহজ ও শক্তিশালী করে তোলে।

React শুধুমাত্র UI-এর কাজ করে। কিন্তু একটি সম্পূর্ণ application তৈরিতে আরও অনেক কিছু লাগে — যেমন ডেটা fetching, Routing, Caching, Font & Image Optimization, Client & Server Side Rendering, SEO ইত্যাদি।

Next.js এই সবগুলো built-in সুবিধা দেয়।

## এই সেকশনে যা শিখব

- **Rendering Methods** — SSG, SSR, ISR, CSR
- **React Server Component** ও RSC Payload
- **Next.js Caching Strategy** — Router Cache, Full Route Cache, Request Memoization, Data Cache
- **Next.js ইনস্টলেশন** ও প্রজেক্ট সেটআপ
- **App Router** ব্যবহার
- **Form Handling** — Controlled ও Uncontrolled Component

শুরু করতে বাম দিকের sidebar থেকে যেকোনো টপিক বেছে নিন।
