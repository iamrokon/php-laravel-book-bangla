# CSS Combinators

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস কম্বিনেটর (Combinators) কি এবং বিভিন্ন প্রকার কম্বিনেটরের কাজ উদাহরণসহ লিখ

সিলেক্টরদের মধ্যে সম্পর্ক তৈরি করার জন্য কম্বিনেটর ব্যবহৃত হয়। এটি মূলত ৪ ধরণের হয়ে থাকে:

### ১. Descendant Selector (space)
কোনো এলিমেন্টের ভিতরের সব নির্দিষ্ট এলিমেন্টকে সিলেক্ট করে, তারা যতই গভীরে থাকুক না কেন।
```css
div p {
    color: blueviolet; /* div-এর ভিতরে যত p আছে সব সিলেক্ট হবে */
}
```

### ২. Child Selector (>)
শুধুমাত্র সরাসরি বা প্রথম স্তরের চাইল্ডদের সিলেক্ট করে।
```css
div > p {
    color: tomato; /* div-এর সরাসরি ভিতরে থাকা p গুলো শুধু সিলেক্ট হবে */
}
```

### ৩. Adjacent Sibling Selector (+)
একটি এলিমেন্ট শেষ হওয়ার ঠিক পরের এলিমেন্টটিকে সিলেক্ট করে।
```css
div + p {
    color: blue; /* div-এর ঠিক পরেই থাকা একটিমাত্র p সিলেক্ট হবে */
}
```

### ৪. General Sibling Selector (~)
একটি এলিমেন্ট শেষ হওয়ার পর তার সাথে একি লেভেলে থাকা সব পরবর্তী এলিমেন্টকে সিলেক্ট করে।
```css
div ~ p {
    color: aqua; /* div-এর পর যতগুলো p আছে সব সিলেক্ট হবে */
}
```
