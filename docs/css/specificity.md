# CSS Specificity (প্রাধান্য নির্ধারণ)

যদি একই এলিমেন্টে একাধিক সিলেক্টর দিয়ে ভিন্ন ভিন্ন স্টাইল দেওয়া হয়, তবে ব্রাউজার কোনটি দেখাবে তা নির্ভর করে **Specificity** বা প্রাধান্যের উপর।

### স্পেসিফিসিটি হিসাবের নিয়ম (হিয়ারার্কি)
ব্রাউজার একটি পয়েন্ট সিস্টেমের মাধ্যমে এটি হিসাব করে:
1.  **Inline Style:** ১০০০ পয়েন্ট (সবচেয়ে বেশি)
2.  **ID Selector:** ১০০ পয়েন্ট
3.  **Class/Pseudo-class/Attribute Selector:** ১০ পয়েন্ট
4.  **Element/Pseudo-element:** ১ পয়েন্ট

### উদাহরণ
```html
<p id="test" class="para">Lorem ipsum...</p>
```
```css
#test { color: red; }    /* ১০০ পয়েন্ট */
.para { color: blue; }  /* ১০ পয়েন্ট */
p { color: green; }     /* ১ পয়েন্ট */
```
এখানে টেক্সটের কালার **Red** হবে। কারণ আইডির স্পেসিফিসিটি ১টি ক্লাস বা ট্যাগের চেয়ে অনেক বেশি।

### কম্বিনেশন হিসাব
সিলেক্টর যত বড় হবে তার স্পেসিফিসিটিও তত বাড়বে।
- `p` => ১ পয়েন্ট
- `.para` => ১০ পয়েন্ট
- `p.para` => ১১ পয়েন্ট (১০+১)
- `div.child .para` => ২০ পয়েন্ট (১০+১০)
- `#test p.para` => ১১১ পয়েন্ট (১০০+১+১০)

### !important
যদি আপনি চান কোনো স্টাইল সব ধরণের স্পেসিফিসিটি ডিঙিয়ে কাজ করবে, তবে ভ্যালুর পাশে `!important` লিখে দিতে হবে।
```css
p {
    color: green !important; /* এটি ১ পয়েন্ট হলেও এটিই কাজ করবে */
}
```

> [!WARNING]
> ড্রিলিং বা ডিজব্যাগিং এর বিশেষ পরিস্থিতি ছাড়া `!important` ব্যবহার করা এড়িয়ে চলা উচিত, কারণ এটি কোড মেইনটেইন করা কঠিন করে দেয়।
