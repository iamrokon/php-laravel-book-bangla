# CSS Box Sizing

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস বক্স সাইজিং (Box Sizing) কি এবং content-box ও border-box এর পার্থক্য উদাহরণসহ লিখ

বক্স মডেলের হিসাব সহজ করার জন্য `box-sizing` প্রোপার্টি ব্যবহৃত হয়।

### ১. content-box (Default)
এটি ডিফল্ট সিস্টেম। এখানে আপনি যদি প্যাডিং বা বর্ডার যোগ করেন, তবে সেটি মূল উইডথ-এর সাথে যোগ হয়ে এলিমেন্টটিকে বড় করে দেয়।
- মোট উইডথ = width + padding + border

### ২. border-box
এটি সবচেয়ে জনপ্রিয় পদ্ধতি। এখানে আপনি যদি প্যাডিং বা বর্ডার যোগ করেন, তবে সেটি মূল উইডথ-এর বাইরে না গিয়ে ভিতরের দিকে কমে যায়। ফলে এলিমেন্টের সাইজ বাড়ে না।
- মোট উইডথ = আপনার দেওয়া নির্দিষ্ট width

```css
.test {
    width: 350px;
    padding: 50px;
    border: 10px solid #fbc531;
    box-sizing: border-box; /* এটার ফলে মোট উইডথ ৩৫০px-ই থাকবে */
}
```

### কেন এটি ব্যবহার করবেন?
হিসাব ছাড়া নির্ভুল লেআউট তৈরির জন্য এটি অপরিহার্য। আধুনিক সব ডেভেলপার পুরো প্রজেক্টের শুরুতে এটি সেট করে নেন:

```css
*,
*::after,
*::before {
    box-sizing: border-box;
}
```
এটি স্টাইলশিটের একদম শুরুতে ইউনিভার্সাল সিলেক্টরে দিলে আপনার পুরো প্রজেক্টের বর্ডার এবং প্যাডিংয়ের হিসাব সহজ হয়ে যাবে।
