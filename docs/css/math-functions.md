# CSS Math Functions

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস ম্যাথ ফাংশনসমূহ (যেমন calc, min, max) কি এবং এদের ব্যবহার উদাহরণসহ লিখ

CSS-এ ক্যালকুলেশন করার জন্য কিছু বিল্ট-ইন ফাংশন রয়েছে যা লেআউট তৈরিতে খুব সাহায্য করে।

### ১. calc()
এটি যোগ, বিয়োগ, গুণ, বা ভাগ করার জন্য ব্যবহৃত হয়। বিশেষ করে ফিক্সড পিক্সেল এবং পারসেন্টেজ একসাথে ব্যবহার করতে এটি অতুলনীয়।
```css
.container {
    /* পুরো উইডথ থেকে ২০০px বাদ দিয়ে বাকিটা নিবে */
    width: calc(100% - 200px); 
}
```

### ২. min()
একাধিক ভ্যালুর মধ্যে যেটি ছোট সেটি গ্রহণ করবে। এটি রেসপনসিভ ডিজাইনে চমৎকার কাজ করে।
```css
.box {
    /* উইডথ ৭০% হবে, কিন্তু ৭০০px এর বেশি হবে না */
    width: min(70%, 700px); 
}
```

### ৩. max()
একাধিক ভ্যালুর মধ্যে যেটি বড় সেটি গ্রহণ করবে।
```css
.box {
    /* উইডথ ৭০% হবে, কিন্তু ৫০০px এর নিচে নামবে না */
    width: max(70%, 500px); 
}
```

### ৪. clamp()
এটি ৩টি ভ্যালু গ্রহণ করে (Minimum, Preferred, Maximum)। এটি এলিমেন্টের সাইজ একটি রেঞ্জের মধ্যে রাখতে সাহায্য করে।
```css
h1 {
    /* ফন্ট সাইজ সর্বনিম্ন ২০px, পছন্দসই ৫vw, এবং সর্বোচ্চ ৫০px */
    font-size: clamp(20px, 5vw, 50px);
}
```
*(ইউজারের দেওয়া টেক্সটে clamp ছিল না, তবে এটি আধুনিক CSS-এর অবিচ্ছেদ্য অংশ)*
