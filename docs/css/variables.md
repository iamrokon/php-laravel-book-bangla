# CSS Variables

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস ভেরিয়েবল (Variables) কি এবং এটি কীভাবে ডিক্লেয়ার ও ব্যবহার করতে হয় উদাহরণসহ লিখ

CSS ভেরিয়েবল বা কাস্টম প্রোপার্টি ব্যবহার করে আপনি আপনার স্টাইলশিটে নির্দিষ্ট ভ্যালু জমা রাখতে পারেন এবং পরবর্তীতে সেগুলো বারবার ব্যবহার করতে পারেন। এর ফলে প্রজেক্টের কালার বা সাইজ পরিবর্তন করা অনেক সহজ হয়ে যায়।

### ১. ভেরিয়েবল ডিক্লেয়ার করা (:root)
সাধারণত ভেরিয়েবলগুলোকে `:root` সিলেক্টরে লেখা হয় যাতে তারা পুরো প্রজেক্টে গ্লোবাল হিসেবে কাজ করে। ভেরিয়েবলের নামের শুরুতে অবশ্যই ডাবল ড্যাশ (`--`) দিতে হবে।

```css
:root {
    --primary-color: #00b894;
    --secondary-color: #dfe6e9;
    --dark-color: #2d3436;
    --white: #ffffff;
    --default-width: 90%;
}
```

### ২. ভেরিয়েবল ব্যবহার করা (var)
ভেরিয়েবল ব্যবহার করার সময় `var()` ফাংশনটি ব্যবহার করতে হয়।
```css
body {
    background: var(--secondary-color);
    font-family: 'Poppins', sans-serif;
}

.card {
    background: var(--dark-color);
    color: var(--white);
    width: var(--default-width);
    margin: 20px auto;
}
```

### ৩. ভেরিয়েবলের সুবিধা
ধরা যাক, আপনার প্রজেক্টের ১০০০ জায়গায় সবুজ কালার ব্যবহার করা হয়েছে। এখন আপনার ক্লায়েন্ট যদি বলে সবুজ পছন্দ না, নীল চাই। ভেরিয়েবল ব্যবহার করলে আপনি শুধু `:root`-এ গিয়ে এক জায়গায় কালার কোড পরিবর্তন করলেই পুরো ওয়েবসাইট আপডেট হয়ে যাবে।

```css
:root {
    --primary-color: #0984e3; /* এখন সবকিছু নীল হয়ে যাবে */
}
```

### ৪. লোকাল ভেরিয়েবল
আপনি চাইলে কোনো নির্দিষ্ট ক্লাসের ভিতরেও শুধু সেই ক্লাসের জন্য ভেরিয়েবল নিতে পারেন।
```css
.button {
    --btn-padding: 10px 20px;
    padding: var(--btn-padding);
}
```
