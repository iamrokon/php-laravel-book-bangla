# CSS Display

CSS-এ এলিমেন্টগুলো স্ক্রিনে কীভাবে দেখাবে তা নির্ধারণ করতে `display` প্রোপার্টি ব্যবহৃত হয়।

### ১. Block vs Inline vs Inline-block
- **Block:** এটি পুরো লাইন দখল করে নেয়। যেমন: `<h1>`, `<p>`, `<div>` ইত্যাদি।
- **Inline:** এটি শুধুমাত্র ততটুকুই জায়গা নেয় যতটুকু এর কনটেন্ট। এর আগে-পিছে অন্য এলিমেন্টে বসতে পারে। যেমন: `<span>`, `<a>` ইত্যাদি।
- **Inline-block:** এটি ইনলাইনের মত কাজ করে কিন্তু এতে হাইট-উইডথ এবং প্যাডিং-মার্জিন সেট করা যায়।
- **None:** এটি এলিমেন্টটিকে পুরোপুরি পেজ থেকে সরিয়ে দেয় (অদৃশ্য করে দেয়)।

### ২. টাইপ কনভার্ট করা
আপনি চাইলে কোনো ব্লক এলিমেন্টকে ইনলাইন এবং ইনলাইনকে ব্লক-এ রূপান্তর করতে পারেন।
```css
h1 {
    display: inline-block; /* এখন এটি পুরো লাইন দখল করবে না */
}

span {
    display: block; /* এখন এটি পুরো লাইন দখল করবে */
}
```

### ৩. নেস্টিং রুলস (Nesting Rules)
ব্লক এলিমেন্টের মধ্যে ইনলাইন এলিমেন্ট ব্যবহার করা যায়, কিন্তু ইনলাইন এলিমেন্টের মধ্যে ব্লক এলিমেন্ট ব্যবহার করা ইনভ্যালিড।

```html
<!-- Valid ✅ -->
<h2><a href="#">This is Title</a></h2>

<!-- Invalid ❌ -->
<a href="#"><h2>This is Title</h2></a>
```
*(বি:দ্র: HTML5-এ অ্যাংকর ট্যাগের মধ্যে কিছু ব্লক এলিমেন্ট রাখা গেলেও সব ক্ষেত্রে এটি সঠিক প্র্যাকটিস নয়)*
