# CSS Opacity

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস ওপাসিটি (Opacity) কি এবং এলিমেন্টের স্বচ্ছতা নির্ধারণের পদ্ধতি উদাহরণসহ লিখ

কোনো এলিমেন্ট কতটা স্বচ্ছ বা গাঢ় হবে তা `opacity` দিয়ে নির্ধারণ করা হয়। এর মান `0.0` থেকে `1.0` পর্যন্ত হয়।

- `opacity: 1`: পুরোপুরি দেখা যাবে (Default)।
- `opacity: 0.5`: অর্ধেক স্বচ্ছ হবে।
- `opacity: 0`: পুরোপুরি অদৃশ্য হয়ে যাবে (তবে জায়গা দখল করে রাখবে)।

### হোভারে অপাসিটি পরিবর্তন
```css
img {
    opacity: 1;
    transition: 0.4s;
}

img:hover {
    opacity: 0.4; /* মাউস নিলে ঝাপসা হয়ে যাবে */
}
```

### কালারের মাধ্যমে অপাসিটি (RGBA)
মনে রাখবেন, কোনো ডিভে `opacity` দিলে তার ভিতরের লেখাও ঝাপসা হয়ে যায়। যদি আপনি চান শুধু ব্যাকগ্রাউন্ড ঝাপসা হবে কিন্তু ভিতরের লেখা স্পষ্ট থাকবে, তবে `rgba` কালার ব্যবহার করুন।
```css
.card {
    background: rgba(0, 0, 0, 0.5); /* কালো ব্যাকগ্রাউন্ড ৫০% ট্র্যান্সপারেন্ট */
    color: #fff; /* লেখা একদম সাদা এবং স্পষ্ট থাকবে */
}
```

### ট্রানজিশন দিয়ে এনিমেশন (Transition Effect)
টেক্সটে বা ডিভে এনিমেশন সুন্দর করার জন্য আমরা ট্রানজিশন ব্যবহার করি।
```css
.box {
    opacity: 0;
    transition: 0.9s;
}

.box:hover {
    opacity: 1;
}
```
