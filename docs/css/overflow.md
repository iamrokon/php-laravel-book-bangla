# CSS Overflow

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস ওভারফ্লো (Overflow) কি এবং এর বিভিন্ন ভ্যালুর কাজ উদাহরণসহ লিখ

যখন কোনো এলিমেন্টের কনটেন্ট তার নির্দিষ্ট সাইজের (উইডথ ও হাইট) চেয়ে বড় হয়ে যায়, তখন সেটি কীভাবে দেখাবে তা `overflow` দিয়ে নিয়ন্ত্রণ করা হয়।

### এর প্রধান ভ্যালুগুলো:
- `visible`: ডিফল্ট ভ্যালু। কনটেন্ট বক্সের বাইরে চলে গেলেও দেখা যাবে।
- `hidden`: বক্সের বাইরে চলে যাওয়া অংশ পুরোপুরি কেটে যাবে (অদৃশ্য হবে)।
- `scroll`: সবসময় একটি স্ক্রলবার দেখাবে।
- `auto`: যদি প্রয়োজন হয় তখনই স্ক্রলবার দেখাবে।

### উদাহরণ
```css
div {
    width: 300px;
    height: 200px;
    background: #2d3436;
    overflow: auto; /* কনটেন্ট বড় হলে স্ক্রলবার আসবে */
}
```

### নির্দিষ্ট দিকে কন্ট্রোল
আপনি চাইলে আলাদাভাবে X (হরাইজন্টাল) বা Y (ভার্টিক্যাল) অক্ষ বরাবর এটি কন্ট্রোল করতে পারেন:
```css
div {
    overflow-x: hidden; /* ডানে-বামে স্ক্রল হবে না */
    overflow-y: scroll; /* উপরে-নিচে স্ক্রল হবে */
}
```
