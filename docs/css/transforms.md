# CSS Transforms

এলিমেন্টকে ঘোরানো, ছোট-বড় করা বা অন্য কোথাও সরিয়ে ফেলার জন্য ট্রান্সফর্ম ব্যবহৃত হয়।

### প্রধান ট্রান্সফর্ম ফাংশনসমূহ:

১. **translate(x, y):** এলিমেন্টকে তার বর্তমান জায়গা থেকে ডানে-বামে বা উপরে-নিচে সরাতে।
```css
.box:hover {
    transform: translate(50px, 100px); /* ডানে ৫০px এবং নিচে ১০০px সরবে */
}
```

২. **rotate(angle):** এলিমেন্টকে নির্দিষ্ট কোণে ঘোরাতে।
```css
.box:hover {
    transform: rotate(45deg); /* ৪৫ ডিগ্রি ঘুরে যাবে */
    transform: rotate(-180deg);
}
```

৩. **scale(x, y):** এলিমেন্টকে ছোট বা বড় করতে।
```css
.box:hover {
    transform: scale(2); /* দ্বিগুণ বড় হবে */
    transform: scale(0.5); /* অর্ধেক ছোট হবে */
}
```

৪. **skew(angle):** এলিমেন্টকে বাঁকা করতে।
```css
.box:hover {
    transform: skew(20deg);
}
```

### একাধিক ট্রান্সফর্ম একসাথে ব্যবহার
```css
.box:hover {
    transform: rotate(45deg) scale(1.5) translate(10px, 10px);
}
```
> [!NOTE]
> ট্রান্সফর্ম করার সময় এলিমেন্টটি পেজের অন্য কনটেন্টকে ধাক্কা দেয় না, এটি শুধুমাত্র ভার্চুয়ালি পজিশন পরিবর্তন করে। স্মুথ ইফেক্টের জন্য এর সাথে `transition` প্রোপার্টি ব্যবহার করা উচিত।
