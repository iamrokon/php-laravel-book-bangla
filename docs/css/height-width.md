# CSS Height & Width

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস হাইট ও উইডথ (Height & Width) প্রোপার্টি এবং Max-width এর গুরুত্ব উদাহরণসহ লিখ

এলিমেন্টের দৈর্ঘ্য ও প্রস্থ নির্ধারণ করার জন্য `height` এবং `width` প্রোপার্টি ব্যবহৃত হয়।

### Fixed vs Fluid Width
- **Fixed Width:** যখন নির্দিষ্ট পিক্সেল দেওয়া হয় (যেমন: `300px`)। এটি স্ক্রিন ছোট বা বড় হওয়ার সাথে পরিবর্তন হয় না।
- **Fluid Width:** যখন পারসেন্টেজ বা রিলেটিভ ইউনিট দেওয়া হয় (যেমন: `90%`)। এটি স্ক্রিন বা উইন্ডোর আকারের উপর ভিত্তি করে পরিবর্তন হয়।

```css
.parent {
    width: 480px; /* Fixed */
    width: 90%;   /* Fluid */
}
```

### Max and Min Properties
রেসপনসিভ ডিজাইনের সময় এই প্রোপার্টিগুলো খুব দরকারী:
- `max-width`: সর্বোচ্চ কতটুকু বড় হবে।
- `min-width`: সর্বনিম্ন কতটুকু ছোট হবে।

```css
.parent {
    max-width: 1140px;
    min-width: 600px;
}
```

### Height ১০০% পাওয়া
সরাসরি বাচ্চার এলিমেন্টে `height: 100%` দিলে তা কাজ করে না যদি না তার প্যারেন্টের নির্দিষ্ট হাইট থাকে। পুরো পেজের হাইট পেতে চাইলে:
```css
html, body {
    height: 100%;
}

.parent {
    height: 100%; /* এখন এটি পুরো পেজের হাইট পাবে */
}
```

### Inherit
প্যারেন্টের ভ্যালু সরাসরি ব্যবহার করতে `inherit` কীওয়ার্ড ব্যবহার করা হয়।
```css
body {
    height: 50%;
}
.parent {
    height: inherit; /* এটিও ৫০% হাইট পাবে */
}
```
