# CSS Margin & Padding

যেকোনো এলিমেন্টের জায়গা বা স্পেসিং ঠিক করার জন্য মার্জিন এবং প্যাডিং ব্যবহৃত হয়।

### পার্থক্য কী?
- **Margin:** বক্সের বাইরের এরিয়া বা এলিমেন্ট থেকে এলিমেন্টের দূরত্ব।
- **Padding:** বক্সের ভিতরের এরিয়া বা বর্ডার থেকে কনটেন্টের দূরত্ব।

![Margin Padding](/css/box-model-diagram.png) *(বি:দ্র: এখানে ডায়াগ্রাম কল্পনা করুন)*

### কোড উদাহরণ
```css
.parent {
    background: #574590;
    width: 300px;
    height: 300px;
    margin-top: 50px;
    padding-top: 50px;
}
```

### এলিমেন্ট সেন্টারে নেওয়া (Centering)
কোনো এলিমেন্টকে হরাইজন্টালি মাঝখানে নিতে হলে `margin: auto` ব্যবহার করা হয়। তবে এলিমেন্টের একটি নির্দিষ্ট `width` থাকতে হবে।
```css
.parent {
    margin: 20px auto; /* উপরে-নিচে ২০px, বামে-ডানে অটো (মাঝখানে) */
}
```

### মার্জিন ও প্যাডিংয়ের Shorthand
- `margin: 10px;` (চারপাশে ১০px)
- `margin: 10px 20px;` (উপরে-নিচে ১০px, ডানে-বামে ২০px)
- `margin: 10px 20px 30px 40px;` (উপরে ১০px, ডানে ২০px, নিচে ৩০px, বামে ৪০px - ঘড়ির কাঁটার দিকে)

> [!IMPORTANT]
> কাজ শুরু করার আগে সবসময় ডিফল্ট ব্রাউজার মার্জিন ও প্যাডিং জিরো করে দেওয়া ভালো প্র্যাকটিস:
> ```css
> * {
>     margin: 0;
>     padding: 0;
> }
> ```
