# CSS Nth-child & Advanced Selectors

> [!IMPORTANT]
> **★ ইন্টারভিউয়ের জন্য গুরুত্বপূর্ণ প্রশ্ন:** সিএসএস এনথ-চাইল্ড (Nth-child) ও অ্যাডভান্সড সিলেক্টরসমূহের ব্যবহার উদাহরণসহ লিখ

একাধিক চাইল্ড এলিমেন্টের মধ্য থেকে নির্দিষ্ট কিছু এলিমেন্ট সিলেক্ট করার জন্য `nth-child` অত্যন্ত কার্যকর।

### ১. বেসিক সিলেক্টর
- `:first-child`: প্রথম চাইল্ড সিলেক্ট করবে।
- `:last-child`: শেষ চাইল্ড সিলেক্ট করবে।
- `:nth-child(2)`: একদম ২ নম্বর এলিমেন্টটি সিলেক্ট করবে।
- `:nth-last-child(2)`: শেষের দিক থেকে দ্বিতীয় এলিমেন্টটি সিলেক্ট করবে।

### ২. বিজোড় ও জোড় সিলেক্টর
লিস্ট বা কার্ড ডিজাইনের সময় এটি খুব কাজে লাগে।
- `:nth-child(odd)` বা `:nth-child(2n+1)`: সব বিজোড় সংখ্যা (১, ৩, ৫...) সিলেক্ট করবে।
- `:nth-child(even)` বা `:nth-child(2n)`: সব জোড় সংখ্যা (২, ৪, ৬...) সিলেক্ট করবে।

### ৩. গাণিতিক ফর্মুলা (n)
এখানে `n` মানে হলো ০ থেকে শুরু হওয়া একটি সংখ্যা।
- `:nth-child(n)`: সব এলিমেন্ট সিলেক্ট হবে।
- `:nth-child(n+4)`: ৪ নম্বর থেকে শুরু করে পরের সবগুলো সিলেক্ট হবে (৪, ৫, ৬, ৭...)।
- `:nth-child(3n+2)`: এটি প্রতি ২ ঘর বাদ দিয়ে ৩ নম্বর এলিমেন্টটি সিলেক্ট করবে। অর্থাৎ ২, ৫, ৮, ১১... এভাবে।

### উদাহরণ কোড
```css
.child {
    background: #b33939; /* Default Color */
}

/* প্রথম ও শেষ সবুজ হবে */
.child:first-child,
.child:last-child {
    background: #474787;
}

/* ৪ নম্বরটি কালার পাল্টাবে */
.child:nth-child(4) {
    background: #cc8e35;
}
```

> [!TIP]
> `nth-child` ব্যবহার করার সময় প্যারেন্ট ডিভের মধ্যে একই ধরণের ট্যাগ থাকা ভালো। ভিন্ন ট্যাগ থাকলে মাঝেমধ্যে আশানুরূপ ফল পাওয়া যায় না, সেক্ষেত্রে `:nth-of-type()` ব্যবহার করা যেতে পারে।
